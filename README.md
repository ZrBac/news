# 资讯

一个日常使用的小网站：看新闻、查汇率、找杭州的去处，也能读指南、玩小游戏。

## 可以做什么

| 入口 | 功能 |
| --- | --- |
| 资讯 | 每日速览与分类阅读，支持搜索、日期筛选、收藏和来源状态查看 |
| 今晚 | 按到家时间与精力，继续阅读、摄影、写作、做饭等兴趣项目，也能挑选附近活动 |
| 周末 | 先看推荐，需要时展开地点库与共用记录；可提建议、手动重新检索 |
| 汇率 | 美元、日元、泰铢兑人民币的近一个月走势、金额换算与 30 天最低提醒 |
| 杭州房价 | 成交报告、市场数据与楼盘资讯，可继续查看自动采集的房源 |
| 生活指南 | 按章节阅读、搜索和收藏《高性价比人生指南》 |
| 小游戏 | 纸牌、数独、卡牌地牢、塔防、俄罗斯方块、扫雷等触屏小游戏 |

新闻按栏目整理，去处独立展示。部分资讯摘要和活动推荐经过 AI 整理，保留原文与来源，方便核对。

每日速览优先展示重大公共消息，再兼顾不同栏目。央视新闻列表与现有订阅共同补充消息；正式放假安排等公共通知即使离开最新列表，也会保留为当天的速览候选。

百度、微博、澎湃和财联社热榜用于发现遗漏话题，直接读取媒体原文或补查有明确发布时间的报道。速览优先纳入最多 5 个不同热点；同一话题的多篇报道合并，近 48 小时发布且当前仍上榜的消息也可进入当天速览，保留实际发布日期。同类新闻参考上榜情况排序，显示“新上榜”“较上次升温”等标记；初次采集只建立比较基线。热榜随新闻一起更新，排名变化由程序计算，不增加模型请求。来源失败时保留上次记录并标明状态。

各新闻栏目都会补读近期原文，按栏目提炼一两句有依据的要点：民生侧重办理条件与时间，财经保留统计口径，游戏交代平台与开放时间等。每轮轮流处理各栏目，新消息优先；无法读取正文或核对依据时保留原摘要，不影响正常更新。

“今晚”可以记下本次成果和下次接着做什么，已开始的项目会优先展示。打开普通网址或桌面安装版即可自动同步偏好、活动标记和积累文字，无需连接或登录；离线先保存在本机，联网后补传。当前使用一份共用记录，不区分访客身份。积累文字不会作为 AI 推荐输入，照片和录音仍由自己保管；记录也能导出、导入。每天的新选题只用于尚未开始的项目，休息无需记录或打卡。

## 更新与离线

- 新闻在北京时间每天 9、11、13、15、17、19、21 点采集，夜间暂停；去处补充检索和房源仍在 9 点、16 点检查，GitHub Actions 完成采集与发布。实际完成时间仍受来源、队列和发布耗时影响。
- 页面上的“刷新资讯”可以随时按需请求一次更新。已有任务时复用该任务，重复请求有冷却时间。
- 周末页的“调整推荐”可以保存两人共用的出游建议，也可以“重新找一批”，立即重新检索活动和地点并筛选，不受当天检索时段限制。重复检索间隔 15 分钟；已有采集任务时需等它完成。页面会显示同步、提交和检索进度；关闭后重新打开会继续查询原任务，连接中断时可点“查看进度”。建议离线先保存，联网同步后用于下一轮推荐；同步超时会保留输入并恢复按钮。
- 去处里的“现在做什么”在点击后即时生成三个建议，按北京时间、可用时间、在家或出门、本次想法及共用偏好筛选，同时获取五常附近天气。明确选出门时，有足够场所就只给出门选择；资料不足时说明备选。旧建议中的相对日期按保存日期解释。无需等待采集发布；场所沿用已收录资料，营业与余位需另行确认。提交后在云端生成，关闭页面或短暂断网不会取消已接收的任务；重新打开只查询原结果，不重复生成。云端请求和结果保留 24 小时，最近一次结果和输入仍保存在当前设备。生成失败后可手动重试，不会读取积累文字。
- 普通刷新会读取最新页面，无需再手动点击版本更新提示。
- 支持安装到桌面。指南、小游戏和房源可在各自页面准备离线资源；新闻和收藏可读取已保存的内容。
- iPhone 添加到主屏幕后，从桌面图标联网打开一次，完成离线准备后再断网使用。

## 项目结构

前端使用原生 HTML、CSS 和 JavaScript，采集与构建使用 Python 标准库。GitHub Pages 托管网页，GitHub Actions 定时采集并发布，Cloudflare Workers 提供刷新协调、去处记录同步和即时建议。

```text
news/                 页面、样式、脚本与内容来源配置
scripts/              采集、内容整理和静态构建
tests/                数据规则、浏览器、离线与升级检查
ops/cloudflare/       云函数及其测试
.github/workflows/    自动检查与发布
```

## 本地预览

使用 Python 3.12，先将 `NEWS_SITE_URL` 设置为实际部署地址（HTTPS，不带结尾斜杠），再在仓库根目录执行：

```sh
python3 scripts/previous_snapshot.py --url "$NEWS_SITE_URL/data/news.json" --output news/data/news.json
python3 scripts/build_news.py
python3 -m http.server 8765 --bind 127.0.0.1 --directory _site
```

打开 <http://127.0.0.1:8765>。新闻和相关数据沿用公开快照；未单独采集时，房源使用仓库内的初始数据。生成结果位于 `_site/`，不直接修改生成文件。

## 检查与维护

```sh
python3 -m unittest discover -s tests -v
npm ci --prefix tests/browser
tests/browser/node_modules/.bin/playwright install --with-deps chromium
PLAYWRIGHT_MODULE="$PWD/tests/browser/node_modules/playwright" node tests/check-mobile.cjs
```

浏览器检查使用 Node.js 22 或更新版本，覆盖资讯、去处、汇率、房价、指南、全部小游戏，以及手机布局、旧版浏览器兼容和离线恢复。

默认分支为 `main`，网站代码推送后自动检查并发布。站点地址由部署环境的 `NEWS_SITE_URL` 提供，源码与文档不绑定具体域名；本地未配置时使用示例地址。详见[网站维护说明](news/README.md)和[运行说明](ops/README.md)。
